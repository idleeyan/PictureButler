## 0. 身份与定位（先定调，再动手）

**产品 UI 设计师视角**：界面 90% 时间在「刷图库 / 找人 / 找标签 / 复制提示词」，不是展示页。

| 维度 | 判断 |
|------|------|
| 风格锚点 | **Linear / Raycast / Eagle 桌面端**的深色工具感：密度可控、强调键鼠效率、强调色只编码状态 |
| 氛围词 | 冷静、紧凑、可信赖、本地工具——不是社交相册，也不是营销落地页 |
| 反锚点 | 不要变成「ComfyUI 花哨插件」、不要「Windows 11 Fluent 纯白大圆角」、不要「游戏启动器」 |
| 一句话目标 | 用户打开后**三秒内找到图、看清识别状态、一键完成操作**；拖动窗口、翻页、多选都「跟手且克制」 |

### 0.1 现状体检（基于现有 `src-native` XAML / 扩展 popup 实读）

**做得对的（保留，不要推倒重来）**

- 已有完整深色 token 骨架（`App.xaml`：Bg / Panel / Text / Accent / Star）。

| P2 | 品牌符号弱 | 标题栏仅 `◆` + 文案 | 窗口截图辨识度低 |
| P2 | 对话框风格分裂 | `InputBox`/`PromptEdit` 无边框 vs `FacePicker`/`PersonPicker` 系统边框 | 弹窗气质不一致 |
| P2 | 运动几乎为零 | 仅关闭按钮有 0.1s 色变 | 选中、翻页、Toast 缺「有响应」感 |
| P2 | 键盘焦点不可见 | 无统一 FocusVisualStyle | 方向键导航（已有）看不清焦点在哪 |

## 1. 设计原则（冲突时按序遵守）

1. **图优先**：任何装饰不得抢缩略图、人脸、标签的注意力；强调色用于状态，不用于大面积背景。
2. **一套 token**：所有颜色、字号、间距、圆角只允许引用资源键；禁止业务 XAML 再写死 `#RRGGBB`。
3. **操作有主次**：每屏最多 1 个 Primary，0–2 个 Secondary，其余 Ghost；危险操作永远独立色相。
4. **状态可读**：加载 / 空 / 错误 / 部分成功必须有结构化视觉，而不是一行灰字。
5. **密度可调**：紧凑（默认）与宽松两档；默认服务 1280×800 长时间盯屏。
6. **不动功能契约**：按钮 Click 路径、快捷键、托盘、HTTP、识别写库一律不改；只改呈现层。

## 3. 组件体系

### 3.1 按钮（解决主次塌陷）

| 变体 | 底 / 边 / 字 | 使用场景 |
|------|--------------|----------|
| **Primary** | `Accent` 底、白字、无边或极细高光 | 每屏 ≤1：「＋ 新建」「保存」「测试并保存」 |
| **Secondary** | `N400` 底、`N600` 边、`N900` 字 | 常规操作：多选、翻页、浏览… |
| **Ghost** | 透明底、hover `N350`、`N800` 字 | 标题栏、星标、关闭、次要取消 |
| **Danger** | 透明底、hover `DangerSoft`、字 `Danger`；或删除时描边红 | 删除所选、删除人物、关闭窗 |
| **DangerFill** | `Danger` 底、白字 | 仅确认弹层中的最终确认 |
| **IconBtn** | Ghost + 24/28 图标 + ToolTip | 标题栏、卡片角操作 |

**现状映射**：`ActionBtn` 整体降为 Secondary；「＋ 新建」升 Primary；所有「删除*」拆为 Danger；标题栏 CaptionBtn 保持 Ghost。

### 3.2 输入

- 搜索框：`N100` 底、`N400` 边、`R3`、高 34；focus 边 `Accent`；左侧可预留 16px 搜索图标槽（无图标时靠 padding 平衡）。
- 多行（提示词内容）：同底色，focus 同规则，内 padding 12×8。
- ComboBox：统一 `FilterCombo`；选中项文字 `#7FA8FF`；弹层 `N200` 底 + `N500` 边 + 阴影 `0 8 24 rgba(0,0,0,.45)`。

### 3.3 卡片家族（打破同质）

| 卡片 | 底色 | 边 | 圆角 | 特征差异 |
|------|------|----|------|----------|
| **图片卡** | `N250` | 无 → 选中 `AccentGlow` 1.5 | `R3` | 缩略图占满主体，文件名 `TypeMicro`；hover 边 `N500` + 缩略图轻微提亮 |
| **提示词卡** | `N250` | 选中 `Accent` | `R2` | 左图右文两栏；星标色 `Star`；正文两行截断 |
| **人物卡** | `N250` | hover `N500` | `R4` | 圆头像 80 + 姓名 + 张数；可加底部细进度条预留「识别中」 |
| **人脸选卡** | `N250` | hover `Accent` | `R3` | 96 方图 + 置信度 `TypeMicro` |
| **设置分组** | `N250` | 无 | `R4` | 标题在组外用 `Accent` 小节标；组内条目用分隔线 `N500` 而非再嵌套卡片 |
| **标签芯片** | `N350` | 无 | 全圆 | 字 + 计数；hover 边 `AccentDim`；**已加入 AND 筛选的芯片**用 `AccentSoft` 底 + `Accent` 字 |

### 3.4 状态徽章（视觉资产强化）

保持「脸 / 标 / 词」三枚，但升级：

- 尺寸：高 16，圆角 4，字 `TypeMicro` SemiBold。
- 未做：底 `#454B61`，字 `N800`（弱化未做，不再纯白）。
- 已做：脸 `Success`、标 `Info`、词 `Warn`，字白。
- hover ToolTip 说明含义（已有则保留）。
- 可选 v2：未做时改为半透明 + 低饱和，避免未做状态「比已做更抢眼」。

### 3.5 导航

- 侧栏 200px；分组标签「管理 / 工具」`TypeCaption` + `N700`。
- 项高 36，圆角 `R2`；未选中字 `N800`；hover `N350`；选中 `AccentDim` 底 + 白字。
- 图标槽 16×16 预留（首期可继续纯文字，但布局留 16px 左内距，避免二期再改间距）。
- 「图片库」红点徽章：`Danger`，仅当 ComfyUI 新增未读；点击进图库后清除。

### 3.6 菜单 / 提示 / 滚动条

| 控件 | 目标 |
|------|------|
| ContextMenu | 深色：底 `N200`，边 `N500`，字 `N900`，hover `N350`，Separator `N500`，危险项字 `Danger` |
| ToolTip | 深色浮层：底 `N100`，边 `N500`，字 `N900`，`TypeCaption`，max-width 280，内距 8×6 |
| ScrollBar | 宽 10；轨道透明/`N150`；滑块 `N500`，hover `N600`；圆角 999 |
| Loading | 遮罩 `#B010131A` 保持；中心胶囊升级：底 `N350`、圆点/旋转用 `Accent`、字 `N900` |
| Toast | 右下角 280 宽；底 `N350` + 左 3px `Accent`/`Warn`/`Success`；自动 4s；可点 |

### 3.7 对话框统一

| 类型 | 窗样式 | 标题栏 | 用途 |
|------|--------|--------|------|
| **Shell（轻）** | `WindowStyle=None` + 自绘 40px 标题栏 | 有 | 输入框、编辑提示词、确认 |
| **Picker** | `None` + 自绘，或统一 Shell | 有 | 人脸选择、人物合并 |
| **系统壳** | 仅文件夹选择等系统 API | — | 浏览目录 |

全部子窗底色 `N50`/`N200`，与主窗一致；取消/确定：取消 Secondary，确定 Primary；删除确认确定为 DangerFill。

## 4. 布局系统

### 4.1 主窗骨架（保持，微调）

```
┌─ TitleBar 44px ─────────────────────────────────────────┐
│ ◆ PictureButler              [─] [□] [✕]                │
├─ Nav 200 ────┬─ Content ────────────────┬─ Detail 360 ─┤
│ 管理         │ Toolbar 48–56            │ (提示词详情)  │
│  提示词      │ Tabs / Filters           │              │
│  图片库 ·    │ ── Grid / List ────────  │              │
│ 工具         │                          │              │
│  设置        │ Footer: page / empty     │              │
│ 版本卡       │                          │              │
└──────────────┴──────────────────────────┴──────────────┘
```

- 详情栏：提示词模式固定 360；图片库模式**默认收起**（现状若已收起则保持）；动画 180ms 滑入。
- 内容左右边距统一 20（`S5`）。

### 4.2 图片库工具栏重排（P0，解决按钮海）

拆成两行信息架构，而不是继续横排堆按钮：

```
行1（56px）：[搜索框 flex][排序][状态][文件夹][计数]
行2（40px）：[全部|人物|标签] … 模式操作区（居中/靠右）… [多选][主操作]
```

**模式操作区规则**

| 模式 | 行2 右侧显示 |
|------|----------------|
| 全部·默认 | Ghost「多选」+ Secondary「识别人脸」+ Secondary「AI 打标」 |
| 全部·多选 | 已选 N + 全选 + 识别人脸 + AI 打标 + Danger 删除所选 + 取消 |
| 标签相册 | 标签名 + 「加入筛选(且)」+ 返回；已叠加则显示已选标签芯片条 |
| 人物相册 | 人物名 + 张数 + 重命名/换封面/合并/删除（删除为 Danger） |

多选条可用**一条横向 ChipBar** 吸附在行2，避免再撑高。

### 4.3 图片网格

- 格子逻辑尺寸保持约 168×196（虚拟化已验证），视觉上：
  - 缩略图圆角 `R2`，背景 `N100`（占位）。
  - hover：整卡边 1px `N500`，缩略图 opacity 1.05（或亮度 +4%）。
  - 选中：边 `AccentGlow` 1.5 + 底 `AccentSoft`；勾选框左上 24。
  - 文件名区高度固定 2 行，避免卡高跳动。
- 空态：居中「TypeDisplay 主句 + TypeBody 副句 + Primary 去设置加文件夹 / 清除筛选」。
- 加载：先出壳（卡片底 + 文件名），缩略图渐进；禁止整页白屏。

### 4.4 人物 / 标签

- 人物：卡片 160 宽保持；头像圈描边 1px `N500`（加载中用 shimmer 背景 `N350`）。
- 标签：芯片行距 8；Top200 时顶部说明「显示最常用 200 / 共 N」`TypeCaption`；搜索无结果空态教「换个词或清空」。

### 4.5 查看器

- 画布 `N0`；人脸框：默认 `Success` 1.5px，hover 高亮；可选半透明填充 `rgba(61,154,106,.12)`。
- 前后按钮：半透明 `#CC10131A` + hover 边 `Accent`；位置保持左右居中。
- 底栏：信息与操作分离——上排文字区（提示词/元数据/描述），下排操作；**删除**独立右侧或 Danger 样式，避免和「打开」并排同权。
- 缩放百分比条：右下角保持，`TypeMicro`。

## 5. 分页面视觉目标

### 5.1 主窗 · 提示词页

- 顶栏：搜索 Secondary 容器 + Primary「＋ 新建」+ Secondary「多选」。
- 卡片两栏：左 112 图，右标题/摘要/时间；星标始终可见。
- 详情栏：标题 SemiBold 15；内容块 `N250`；操作四键（复制内容/标题/编辑/删除）Secondary + 删除 Danger。
- 空态：「还没有提示词」+「＋ 新建第一条」。

### 5.2 主窗 · 图片库 · 全部

- 三态徽章 + 文件名；多选左上角。
- 筛选变化时计数区显示「N 张 · 耗时 xx ms」（可观测，灰字）。
- 分页：页码居中，当前页数字 `Accent`；按钮 Secondary。

### 5.3 主窗 · 人物

- 网格 + 顶部「已显示 N 人 · 库内还有已忽略 M」可选说明。
- 进入相册后路径感：「‹ 人物 / 张三」面包屑，返回 Ghost。

### 5.4 主窗 · 标签

- 芯片云；点击进入相册；AND 筛选芯片条固定在搜索框下方，可单个 × 移除。

### 5.5 主窗 · 设置

- 左列表 / 右内容 的二级导航可选（v2）；首期保持纵向分组即可，但：
  - 小节标题：`Accent` + `TypeBody` SemiBold + 上下 12 间距。
  - 分组卡：去掉「卡中卡」；条目之间用 1px 分隔。
  - 状态反馈（ScanStatus / ComfyStatus / PruneStatus）：成功绿、失败红、进行中蓝，不再全灰。
  - 危险区（清理缓存、清理空人物）单独 `DangerSoft` 底提示条说明后果。

### 5.6 查看器 / 选择器 / 输入框 / 编辑窗

- 全部套用 Shell 标题栏与 token。
- 人脸选择：网格 hover 边 `Accent`，当前封面加角标「当前」。
- 人物合并列表：行高 44，hover `N350`，头像 36。

### 5.7 浏览器扩展 Popup（对齐附录）

- 颜色沿用主程序 token 表。
- 按钮圆角 `R2`，高度 28；输入 focus `Accent`。
- 列表项圆角 `R3`，间距 8；状态胶囊 on/off 用 Success/Danger。
- 宽度保持 340；顶部 logo 可与主窗 `◆` 同源。

## 6. 状态与反馈矩阵

| 场景 | 视觉 |
|------|------|
| 首次打开图库 | 网格壳立即出，缩略图渐进；顶部可选 indeterminate 细条 `Accent` 高 2 |

| 搜索无结果 | 空态三件套：主句/副句/按钮（清除筛选） |
| 识别进行中 | 侧栏图片库 badge 数字；卡片上该图「脸」徽章脉冲一次（opacity 120ms×2） |

| 失败 | Toast 或状态文字 `Danger`；可重试则 Secondary「重试」 |
| 本地服务未就绪 | 侧栏 `HttpStatusText`：灰→红/绿点 + 短文案 |

## 7. 可访问性底线

- 正文对比度 ≥ 4.5:1；徽章/UI ≥ 3:1（`N800` on `N250` 需复核，必要时升 `N900`）。
- 焦点环：2px `Accent` 外描边，offset 1；所有可点控件可 Tab 到达。
- 动效遵循系统「减弱动画」时长设为 0。
- 图片卡 ToolTip/文件名作为可访问名；装饰图标必要时补 `AutomationProperties.Name`。
- 危险操作二次确认；删除文案明确「回收站」。

## 8. 分阶段实施（只改视觉层）

### 阶段 V0 —— Token 收敛（约 0.5–1 天）

**目标**：改主题只改一处；消灭双轨色值。

1. 整理 `App.xaml`（或新建 `Themes/Dark.xaml`）完整 token：色/字/距/圆角/动效。
2. 全量替换 `MainWindow` 与子窗硬编码颜色为 `{StaticResource …}`。
3. 字号、间距替换到刻度表。
4. **不改**布局结构、不改 Click。

**验收**：业务 XAML 无硬编码 `#`；主窗打开、切换页签、开查看器无视觉回归。

### 阶段 V1 —— 组件与层级（约 1–1.5 天）

**目标**：按钮主次、卡片家族、菜单/提示/滚动条。

1. 按钮变体拆分（Primary/Secondary/Ghost/Danger）。
2. 图片卡 hover/选中/占位统一；人物卡、标签芯片、设置分组差异化。
3. ContextMenu / ToolTip / ScrollBar 深色化。
4. 三态徽章按新色表重绘。
5. 对话框统一 Shell。

**验收**：图片库页一眼能看出「多选 / 识别 / 打标 / 删除」层级；右键与主 UI 同气质。

### 阶段 V2 —— 布局与空态（约 1 天）

**目标**：工具栏两行化、空态三件套、查看器底栏主次。

1. 图片库 Toolbar 重排（行1 筛选 / 行2 模式操作）。
2. 各空态与错误态。
3. 查看器操作区重排（删除分离）。
4. Toast / NoticeBar 规范落地。

**验收**：1280×800 下工具栏不换行溢出；空态可点出主行动。

### 阶段 V3 —— 细节与扩展（约 0.5–1 天）

1. 品牌：标题栏 logo 字形/矢量 `◆` 升级为更清晰 16px 标记。
2. 焦点环、键盘导航可见性。
3. 运动：选中/Toast/详情栏 120–240ms。
4. 扩展 popup 对齐 token。
5. 设置状态色。

**验收**：Tab 一圈焦点可见；扩展与主窗截图并排「像同一产品」。

### 阶段 V4 —— 可选增强（不阻塞发版）

- 浅色主题（同一 token 架构换映射表）。
- 导航图标槽真实图标。
- 设置二级侧栏。
- 人物卡「识别中」进度。
- 高对比模式。

## 11. Anti-Patterns（明确拒绝）

- **不要**给每个设置项都套一层阴影卡片（卡中卡）。
- **不要**用渐变大底、发光描边、玻璃拟态大面积模糊（WPF 性能也不友好）。
- **不要**主按钮满天飞（识别/打标/多选都是蓝底会毁掉层级）。
- **不要**空态只写「暂无数据」。
- **不要**为了「好看」加插画空态大图——本地工具空态应指向动作。
- **不要**在升级中顺手改 SQL、识别、扩展协议。
- **不要**引入与现有虚拟化不兼容的自适应卡片高度。
